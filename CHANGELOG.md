# Changelog

## 1.0.0

Initial public ChatRail release.

- Local HTTP gateway for WhatsApp.
- MCP stdio integration.
- `whatsapp-web.js` and Baileys provider adapters.
- LID-aware identity handling.
- Persistent local message/contact state.
- Live unread chat and message inspection.
- Outbound allowlist, dedupe, idempotency, and registration checks.
